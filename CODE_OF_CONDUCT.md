# Code of Conduct

## Propósito

StaffTrain es un proyecto académico. La colaboración debe apoyar el aprendizaje, la claridad técnica y el respeto entre integrantes.

## Comportamiento esperado

- Comunicarse con respeto.
- Explicar desacuerdos de forma técnica y clara.
- Cuidar la calidad del código y la documentación.
- Revisar Pull Requests con intención constructiva.
- Reportar errores con pasos reproducibles.
- Reconocer el trabajo de los demás integrantes.

## Comportamiento no aceptado

- Comentarios ofensivos, discriminatorios o personales.
- Uso indebido de issues o Pull Requests.
- Subir datos sensibles o credenciales reales.
- Borrar trabajo de otros sin coordinación.
- Romper intencionalmente la arquitectura del proyecto.

## Resolución de conflictos

Los desacuerdos deben resolverse revisando requisitos, código, evidencia de pruebas y documentación del proyecto. Si el conflicto continúa, debe escalarse al equipo o docente responsable.

## Enfoque académico

Este repositorio existe para aprender y demostrar buenas prácticas en Java, JavaFX, estructuras de datos y arquitectura por capas.

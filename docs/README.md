# Documentación de StaffTrain

Este directorio reúne la documentación técnica, funcional e histórica del proyecto StaffTrain.

## Documentos principales

- [Documentación general](./STAFFTRAIN_DOCUMENTACION.md): descripción del sistema, arquitectura, módulos, requerimientos y referencias.
- [Lógica del sistema](./LOGICA_SISTEMA_STAFFTRAIN.md): explicación de reglas funcionales y flujos internos.
- [Flujos de trabajo](./flujos-trabajo/): procesos paso a paso para pasajero, empleado, administrador, boletos, equipaje, rutas y trenes.

## Carpetas de apoyo

- `assets/`: recursos visuales para documentación, como el logo del README.
- `legacy-csharp/`: código histórico de referencia de la etapa inicial en C#.
- `diagramas/`: carpeta reservada para diagramas del sistema.
- `referencias/`: carpeta reservada para bibliografía y fuentes.
- `bitacora/`: carpeta reservada para registro de avances.
- `capturas/`: carpeta reservada para evidencias visuales de la aplicación.

## Recomendación de uso

Para comprender el proyecto, se recomienda leer en este orden:

1. `README.md` en la raíz.
2. `docs/STAFFTRAIN_DOCUMENTACION.md`.
3. `docs/LOGICA_SISTEMA_STAFFTRAIN.md`.
4. `docs/flujos-trabajo/FLUJO_GENERAL_SISTEMA.md`.
5. Flujos específicos según el rol o módulo.
